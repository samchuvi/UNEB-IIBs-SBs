# Theory Answers
1. A static block is a block of code with the keyword static that belongs to
   the class and is used to initialize static variables.
2. An instance initialization block is a block of code in { } with no name that
   runs every time an object is created, before the constructor.
3. Purpose of static blocks: to do one-time setup for the whole program,
   such as loading configuration settings and initializing static variables.
4. Purpose of instance blocks: to give default values to every object and to
   hold code shared by all constructors.
5. A static block executes once, when the class is first loaded into memory,
   before any object is created and before main() if it is in the main class.
