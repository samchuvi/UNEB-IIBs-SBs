# Static Block (SB)
A static block is a block of code marked with the keyword static.
It belongs to the class, not to any object.
In this system it loads the UNEB exam settings: exam year 2026,
registration fee UGX 165,000 and grading policy D1 - F9.

## When it executes
- Runs only ONCE, when the class is first loaded by the JVM.
- Runs before any object is created.
- The static block of the main class runs even before main().
