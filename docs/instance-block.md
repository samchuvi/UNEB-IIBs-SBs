# Instance Initialization Block (IIB)
An instance initialization block is a block of code written inside { }
with no name and no keyword.
In this system it gives every new student default values:
status = PENDING and exam centre = Not yet assigned.

## When it executes
- Runs EVERY time a new object is created with new.
- Runs just BEFORE the constructor.
- In the program it ran 3 times because 3 students were registered.
